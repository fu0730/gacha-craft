Gacha Craft

作業台でクラフトすると結果がランダムに！ソシャゲ風レアリティ演出付きMod

Forge 1.20.1 v1.0.0 マルチプレイ対応

どんなMod？

作業台でアイテムをクラフトすると、本来のアイテムの代わりにランダムなアイテムが出てくるようになります。排出されるアイテムにはソシャゲ風のレアリティ（N / R / SR / SSR）があり、レアリティに応じた演出が画面に表示されます。

必要なもの

Minecraft Java Edition

PC版（Java Edition）が必要です。Switch/PS/スマホ版では使えません。

導入方法（初めてModを入れる人向け）

1

Minecraft 1.20.1 を一度起動する

Minecraftランチャーを開いて、「起動構成」からバージョン 1.20.1 を選んで一度だけ起動してください。起動したらすぐ閉じてOKです。（これで必要なファイルが作られます）

2

Forge 1.20.1 をインストール

下のボタンからForgeインストーラーをダウンロードして実行してください。

Forge 1.20.1 インストーラーをダウンロード

ダウンロードした forge-...-installer.jar をダブルクリックで開き、「Install client」を選んで「OK」を押すだけ！

jarファイルが開けない場合

Javaがインストールされていない可能性があります。Java 17 をここからインストールしてから再度お試しください。（Windows: .msi / Mac: .pkg を選んでください）

3

Gacha Craft をダウンロード

このページの下にあるダウンロードボタンから gachacraft-1.0.0.jar を入手してください。

4

modsフォルダに入れる

ダウンロードした gachacraft-1.0.0.jar を modsフォルダに入れます。

modsフォルダの開き方

Windows: キーボードで Win + R を押して %appdata%\.minecraft\mods と入力してEnter

Mac: Finderで Shift + Command + G を押して ~/Library/Application Support/minecraft/mods と入力

modsフォルダがない場合は自分で作ってください。

5

Forgeで起動！

Minecraftランチャーを開いて、左下のプロファイルを forge に切り替えて「プレイ」を押せば完了！

作業台で何かクラフトしてみてください。ガチャが始まります！

レアリティ一覧

N
排出率: 60%
棒、土、丸石、砂利、腐った肉、骨 など
演出: アクションバーに表示 + 村人の「No」音
R
排出率: 25%
鉄インゴット、金インゴット、鉄の剣、弓、盾 など
演出: アクションバーに表示 + 経験値オーブ音
SR
排出率: 12%
ダイヤモンド、ダイヤ装備、エンダーパール、エリトラ など
演出: 画面中央に金色タイトル + レベルアップ音
SSR
排出率: 3%
ネザライト装備、エンチャント金リンゴ、ネザースター、ドラゴンの卵 など
演出: 画面中央に紫の大きなタイトル + チャレンジ完了音

マルチプレイで遊ぶ

1

サーバーとクライアント両方にModを入れる

サーバーの mods フォルダと、各プレイヤーの mods フォルダの両方に gachacraft-1.0.0.jar を入れてください。

2

いつも通り接続するだけ

特別な設定は不要です。全プレイヤーの作業台がガチャ化されます。

LAN公開で遊ぶ場合

シングルプレイのワールドを「LANに公開」すれば、同じネットワーク内の友達と遊べます。この場合もお互いにModを入れておけばOKです。

ダウンロード

Forge 1.20.1 が必要です

gachacraft-1.0.0.jar をダウンロード
